## Variables

• Variable stores data.
• Variable has a meaningful name.
• JavaScript manages memory internally.
• Syntax:
> let variableName = value;
• Variables improve code readability and reusability.

### let
- Used to declare a variable.
- The value can be changed later.
- Use `let` only when creating the variable.
- Do not use `let` again while updating the value.

### const

- Used to declare a variable.
- Value cannot be reassigned.
- Use when the value should remain constant.
- Preferred by default in modern JavaScript.

## var
- Older way of declaring variables.
- Can be reassigned.
- Avoid using it in modern JavaScript.

## Best Practice
- Use const by default.
- Use let only when the value changes.
- Avoid var in new projects.
