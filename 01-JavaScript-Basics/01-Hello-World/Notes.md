# Basic Concepts and First JavaScript Program


## First JavaScript Program

```javascript
console.log("Hello World");
```

### Output

```
Hello World
```

---

## Understanding the Syntax

```javascript
console.log("Hello World");
```

| Part | Description |
|------|-------------|
| `console` | JavaScript object used for debugging and displaying output. |
| `log()` | Method used to print data to the console. |
| `"Hello World"` | String value displayed on the console. |
| `;` | Statement terminator (optional but recommended). |

---

## What is `console.log()`?

`console.log()` is a built-in JavaScript method used to display messages, variable values, or program output in the terminal or browser console.

### Example

```javascript
console.log("Automation Testing");
console.log(100);
console.log(true);
```

### Output

```
Automation Testing
100
true
```

---

## Running a JavaScript Program

1. Create a file named `app.js`
2. Write your JavaScript code.
3. Open the terminal.
4. Navigate to the project folder.
5. Run:

```bash
node app.js
```

## Why is Node.js used?

Node.js provides the JavaScript runtime that allows JavaScript code to execute outside the browser.

Without Node.js, JavaScript programs cannot run directly from the terminal.

---

## Real QA Example

Automation engineers frequently use `console.log()` to:

- Print test data.
- Debug scripts.
- Verify variable values.
- Track test execution.

Example:

```javascript
console.log("Launching Browser...");
console.log("Login Successful");
console.log("Test Passed");
```

---

## Best Practices

- Keep messages meaningful.
- Use `console.log()` for debugging during development.
- Remove unnecessary logs before finalizing automation scripts.
- Use proper file names (e.g., `app.js`).
